# V12 Engine Simulator — V1

PWA expérimentale de simulation de cockpit moteur V12.

## Installation GitHub Pages
1. Crée un repository GitHub.
2. Mets **tous les fichiers** de ce dossier à la racine du repository.
3. Dans **Settings → Pages**, active GitHub Pages avec la branche `main` et le dossier `/ (root)`.
4. Ouvre l'URL GitHub Pages sur iPhone.
5. Safari → Partager → **Sur l’écran d’accueil**.

## Commandes
- START ENGINE : démarrer / arrêter.
- THROTTLE : accélérateur.
- − / + : palettes.
- COMFORT / SPORT / SPORT+ : calibration du régime.
- SOUND ON/OFF : audio synthétique V1.

## Important
La V1 utilise un moteur sonore synthétique Web Audio pour que le ZIP fonctionne immédiatement sans fichiers audio externes. Pour une V2, on pourra remplacer/compléter ce système avec de vrais samples V12 multicouches.
